# STC2650 / SCT2650 核查（2026-11-18）

## 结论和边界

- 制造商直接证据支持 **SCT2650STER**，芯洲科技 Silicon Content Technology 的非同步 Buck，ESOP-8L。用户写的是 **STC2650**，不能在采购型号/BOM中把这个拼写差异当作已经确认。可以画“SCT2650STER 候选，待核对用户型号”的可审阅电路。
- 若用户指的确实是 SCT2650：常规每节满充4.2V的6S锂电池最高25.2V，落在该芯片4.5–60V工作范围内。此结论是按电池化学体系假设计算的兼容性判断，不等于已确认电池体系或BMS关断电压。
- 数据表宣传最高5A连续输出，不代表封舱中无散热条件也能稳定供应5A；两只舵机的运行/堵转电流和逻辑、摄像头功率预算尚缺。
- 建议逻辑与舵机各使用独立Buck，输出网络分别5V_SYS和5V_SERVO，两个输出不并联。仅把同一个5V节点分叉并不能获得独立稳压，仍共享5A能力与瞬态压降。两路降压仍共用6S输入及地，不能称为隔离电源。
- 逻辑支路5V用于模块/外围及后级稳压输入；STM32/ESP裸芯片电源仍应按原设计降至所需3.3V，不能把5V直接接裸MCU VDD。

## 具体落图注意

1. 原理图若採用以上5V参考值，应标注为厂家5V/500kHz参考设计，不得把厂商p11的3.3V例图参数整套复制成5V。
2. p11例图的EN分压309k/76.8k对应5.73V启动、4.045V停止，不是6S电池合理的欠压策略；需要按电池/BMS规格重新设置或明确欠压由BMS/系统负责。
3. 7.8µH是参考组合，不是强制唯一电感；替换为常见6.8/8.2/10µH需重新校核峰值电流、纹波及环路。数据表p13建议保守电感饱和电流高于8A典型开关限流，实际还应核实限流最大值及温度降额。
4. 续流二极管在6S降5V时导通占空比较高，是显著热源；要做芯片、电感、二极管热设计。不能把两路各5A直接当成整板保证的50W输出。
5. 7针PWM接口应标清VCC的实际电压、输出或参考电源用途、可用电流和禁止外部电源反灌。舵机3针接口按用户约定VCC/GND/PWM画出，不假设所有现成舵机线序兼容。
6. 舵机地回流和逻辑地应规划回流路径，输入端保护、电容、散热与PCB走线须结合实际布局复核。当前只能完成候选原理图，不能称制造验证完成。
