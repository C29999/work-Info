# Rev F 电池电压采样（评审稿）

## 目标与边界

- 同一时刻只接一款电池：3S、4S或6S。电池与MCU共地，并非电气隔离；不增设电流采样或电量计。
- ADC只测D901反接二极管**之后**的 `BAT_SENSE_PROTECTED`。该值不是电芯端子电压，D901压降随电流和温度变化。BMS RS485若提供SOC，可单独显示，但不可假定三款电池都支持相同协议。
- 串数、化学体系、标称容量和该电池的电压-SOC曲线由设备配置选择；单个总电压不能可靠自动判断串数，更不能用“测得电压÷满充电压”直接求剩余百分比。
- 以下12.6/16.8/25.2V仅是每节满充4.2V的3S/4S/6S**示例**，不是对电池化学体系的认定。电压法只能给粗略SOC，不能测剩余电流、安时容量或准确续航。

## 候选硬件

`J901 BAT_IN` → `F901` → `D901` → `BAT_SENSE_PROTECTED` → `R301 49.9k` → `R307 49.9k` → `BAT_DIV`。`R302 10k` 和 `C301 100nF` 从 `BAT_DIV` 到GND。`BAT_DIV` 经 `U301 TMUX1511` 的S1/D1、`R303 1k`、装配的 `R304 0Ω` 到 `BAT_ADC`（STM32F407 PC0/pin15/ADC1_IN10）；`R305 100k` 从 `BAT_ADC` 到GND。

`U303 TLV809EA29DBZR` 监视+3V3，推挽高有效的运行态驱动 `BAT_SENSE_EN`；`R306 100k` 默认下拉。U301断电保护把高压分压端与未供电的MCU输入断开。这是模拟开关，不是电气隔离器。U301未用通道接GND；C303/C304各100nF就近去耦。此配置的R304为候选**装配**，与Rev E默认DNP不同。

标称静态换算（忽略开关导通电阻和ADC输入负载）：

```text
R下等效 = 10k || (1k + 100k) = 9.099099kΩ
V_ADC / V_保护后 = [R下等效 / (99.8k + R下等效)] × 100k / 101k
V_保护后 ≈ 12.0878 × V_ADC
25.2V → ADC约2.085V；30V → ADC约2.482V
```

在开关断开时，`BAT_DIV` 最坏30V/109.8k×10k≈2.732V，低于U301断电信号端3.6V推荐上限；**仅限稳态、30V输入假设**。F901/D901/D902的额定值和浪涌钳位未选定，超过30V的瞬态、反接、启动/关断、ADC注入电流与漏电/残压需样机验证。没有独立保证钳位的ADC保护器件，不得据此直接投板。3S低电压时两路Buck是否维持输出也须按最终器件和BMS截止测试。

## 固件与台架

1. 配置电池型号、串数、容量及该型号的标定曲线；配置缺失或不匹配时仅显示“电压/电池配置未知”，不要输出SOC百分比。
2. 上电后等待+3V3稳定、U303释放复位且分压RC稳定；候选等待至少500ms。ADC使用足够长的采样时间，多次采样取稳健平均，并以实测VDDA/ADC参考电压换算，不把3.3V电源绝对精度当已知。
3. 按实测分压系数还原保护后母线电压；仅在对应电池、温度和负载/静置条件下查标定的电压-SOC表。带载压降、滞回和老化会改变估计。避免显示虚假的精确百分比，可用宽档位或范围。
4. 第二次上电可重新测量并估计当前电压对应的粗略SOC；断电期间的放电和电池更换无法从历史读数推算。若需要准确累计剩余容量、充放电电流或续航，必须另加电流测量/电量计并维护状态。
5. 样机分别用三款电池测全电压范围，覆盖6S满充、30V稳态边界、低电关断、热插拔、反接及电源下降；测U301断电输入、PC0残压与注入电流、D901压降、ADC校准与噪声。最终锁定F901/D901/D902、阻容额定值、连接器与PCB回流，再做ERC/DRC/温升/EMI验证。
