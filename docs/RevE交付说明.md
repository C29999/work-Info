# Rev E 简明交付说明

更新：2026-11-18。入口为 [index.html](../index.html)，详细图纸见 [整板原理图阅读器](../design/原理图设计.html)。当前为候选电气评审稿，尚未冻结生产设计。

## 电源与主要接口

| 项目 | 当前设计 |
| --- | --- |
| 主电源 | 6S 输入，经保护后进入两路独立 Buck；共用输入和地 |
| 逻辑电源 | U901 输出 +5V，U902 继续降至 +3V3 |
| 舵机电源 | U903 单独输出 +5V_SERVO，不与逻辑 +5V 并联 |
| Buck 型号 | SCT2650STER 候选；用户原写 STC2650，采购型号仍待核对 |
| 五路 PWM | J401 七针：1=+5V，2=GND，3～7=PWM1～5；信号为 3.3V，不承载电机功率 |
| 两路舵机 | J407/J408 三针：1=+5V_SERVO，2=GND，3=PWM；PA6#31/PA7#32，TIM3 AF2 |
| 双主控 | STM32F407 LQFP100；P4C5 核心板以单个四边 88 焊盘器件框呈现 |
| 通信与传感器 | 双 MCU 共用 CAN 总线；BMS、超声波与水下通信分别使用独立 RS485；成品 IMU 使用 I²C |

+5V 与 +5V_SERVO 输出独立但不隔离。舵机堵转、摄像头峰值、逻辑总功耗和封舱散热尚未测定，不能把器件标称电流当成整板保证输出。电源参数依据见 [原厂核验记录](power_verified_rev_e.md)。

## P4 与 C5 烧录

- P4 手动 UART 恢复：使用 3.3V 逻辑 USB-UART，RX 接 TP701（P4 TX），TX 接 TP702（P4 RX），另接公共 GND，板电源按设计供电。
- 按住 SW702 BOOT，按下并松开 SW701 RESET，再松开 BOOT。复位释放时 GPIO35 为低、GPIO36 为高。P4 复位 RC 为 R701 10kΩ / C705 1µF 候选。
- 在对应 P4 项目中使用生成的下载参数，例如 `idf.py -p COMx flash monitor`。固件目标与实际芯片必须匹配；P4、C5 分别烧录。
- P4 USB 调试仍为逻辑端口，尚未完成实体 USB 座、VBUS 和保护电路。
- C5 模块焊盘 4/5/6/7/82 当前全部 NC，需先补齐下载与启动/复位电路。焊盘 82 内部与 P4 GPIO54 共用 C5 复位路径，需避免两个驱动端争用。现有 BOOT/RESET 按键只控制 P4。

阅读器的“ESP 烧录”弹窗可定位这些位置；C5 的空心框表示待引出焊盘。

npm ci
