三种摄像头接口 · USB / CSI / DVP

USB UVC 使用 pad48 DM / pad49 DP，GPIO3 使能限流5V供电，GPIO2接过流反馈。CSI 使用专用差分脚与 GPIO48 XCLK；新增8bit DVP 经 LCD_CAM 用12个GPIO。三路同时采集、编码、SD录像及转发尚未验证。

摄像头控制扩展 · 必须补齐

GPIO22/23 共用 SCCB/I²C；扩展器至少提供 CSI/DVP 各 RESET、PWDN 共4个输出，高速DVP信号保持直连P4。同地址摄像头需I²C隔离/多路复用；扩展器型号、电压、默认态、复位时序与驱动初始化待定，不能把扩展器端口号直接当作P4 GPIO号。

SD 与 C5 分开

C5 已连接 P4 GPIO14–19。按官方映射推导内部采用 slot1；外置卡候选 slot0 的 GPIO39–44，GPIO45 做检测。SD 卡供电来自系统 3.3V；pad66/VDDO4 及固件电压配置未冻结。

水下线缆 · 独立 RS485

UART3：GPIO28 TX / 29 RX / 30 DE → 收发器 → A/B → 岸端。暂按半双工控制/遥测，不承诺视频回传；终端、参考地、隔离保护、缆长与波特率待定。水泵由GPIO31经板外功率驱动控制，LED仍由STM32 PB8控制。

CAN 运行诊断

GPIO20/21 经独立 3.3V 收发器接 F4 与 USB-CAN。无证据显示核心板带 CAN 收发器，本图按外加预算。保留 USB24/25、BOOT/RESET；37/38 仅保留恢复测试点。
