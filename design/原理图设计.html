整板依据与设计边界

整板连接表用于评审，不是EDA网表。

DNP不代表默认导通；相机逻辑端口不代表已经确定FFC针序。

U701按P4C5手册绘制为单个88焊盘核心板；纯P4资料不混用，实物版次仍需核对。

P4C5手册焊盘66为ESP_LDO_VO4，V1.4底板U4标VFB_VO4/LDO_VO4_ADJ；定义差异未闭合，本版不接负载。

3S/4S/6S电池分别配置、不可同时接入；化学体系/容量/工作范围待定，25.2V仅6×4.2V示例。

电源、ESD/隔离、视频链路、ADC过压/断电反灌、执行器失联保护仍需完成工程验证。

  • F4：ST官方管脚库、DS8626及AN4488；沿用原F4核验记录。
  • P4C5核心板手册：p7符号、p8–10脚表、p11启动、p13电气参数及内部原理图缺失。U701为单个88焊盘模块符号，脚号不是裸P4芯片脚号。
  • 纯P4核心板手册：p7–10仅对照型号差异；4–14脚定义与P4C5不同，不能混用。
  • 底板原理图V1.4（2026-04-30）：第1页U4、TF_CARD与CSI区域供外围参考；USB、电源和摄像头电路属于底板。其焊盘66标识与P4C5手册不一致，保持待确认。
  • 开发板使用指南：p3接口概览；p6所附原理图为V1.3。V1.4的CSI有1.8V控制与电平转换，不能据此认定未定型号的相机可接当前3.3V候选接口。
  • 实际IMU载板原理图：第1页P1、RT9013稳压、R4/R5上拉、CH340X与USB共网。
  • SCT2650STER 候选：Rev1.3 p2–3脚表、p12分压/频率、p14二极管、p17表3的5V外围。用户写STC2650，型号待核对；两路输出独立且共地。
  • TPS62130/1/2/3：TPS62132固定3.3V候选，参见本地核验记录。
  • TCA9534 与 TCA9543A：I/O扩展与SCCB隔离候选，当前按3.3V接口；相机1.8V则必须改设计。
  • TPS2051C：USB 5V限流开关候选，0.5A不代表相机峰值一定满足。
  • SN65HVD230与ADI MAX3485：沿用F4已核验脚表；UMW替代料仍未核验。

P4TP701 / TP702：UART TX / RX；TP703：EN；SW701 / SW702：RESET / BOOT。UART 使用匹配的逻辑电平，TX 与 RX 交叉并共地。固件必须针对 P4 构建，不能烧写 C5 / C3 固件。
C5模块 4 / 5：UART RX / TX；6 / 7：GPIO28 / GPIO27；82：C5 复位路径。这些脚当前 NC，需补下载引出与启动 / 复位电路后才能按该路径烧录；不能照搬 C3 脚号。

P4 手动 UART 恢复

  1. 使用 3.3V 逻辑 USB-UART：RX 接 TP701（P4 TX），TX 接 TP702（P4 RX），另接公共 GND。按板电源方案供电。
  2. 按住 SW702 BOOT，按下并松开 SW701 RESET，再松开 BOOT；复位释放时 GPIO35 为低、GPIO36 为高。
  3. 在已有 P4 项目中按生成的下载参数烧录，例如 idf.py -p COMx flash monitor；COMx 替换为实际串口。运行时释放 BOOT 后复位。

C5 必须先补下载电路；模块82内部与P4 GPIO54共享复位路径，需避免外部下载器与P4驱动争用。现有两个按键仅控制P4。

启动模式依据：Espressif P4、Espressif C5。
