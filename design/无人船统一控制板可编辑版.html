统一主板 · 单块 PCB 布局

中央：STM32F4 + ESP32-P4 模块（P4C5资料候选）；外围按传感器、通信、电源、五路 PWM、深度、五个超声波、UART 激光雷达、microSD、LED 与电池 RS485 接口分区；功率驱动板独立制作。

默认显示整块 PCB；点击“放大查看”可读取标注，放大后可左右滚动。窄屏进入编辑时会自动放大。

左上角改为用户提供的成品IMU模块：P1-7/6接PB6/PB7，P1-4接可断开的5V，P1-3/5接地；P1-1/2/8本版NC。模块自带3.3V稳压与4.7k I²C上拉，内部传感器型号和协议待确认。USB调试须断开主板5V并协调总线访问。双MCU仍经CAN收发器通信；STM32保留SWD，P4保留USB下载。

当前为布局评审稿，不是生产用 PCB。CAN 用于固件运行时的诊断和限速日志，不能自动替代首次烧录、断点调试或固件失效后的恢复。总线两端终端电阻留在固定端点，拔除 USB-CAN 不应改变终端配置；控制和心跳报文优先于日志。ESP32-P4 的存储、电源、时钟、去耦和启动外围需补全；外部调试器、无线模块和摄像头位于板外。小屏可左右滑动查看。

驱动板独立制作，主板不集成有刷 H 桥。五路 PWM 的定时器/引脚、逻辑电平、频率/脉宽和上电/复位/失联安全输出待确认；停机信号须按驱动协议确定，不能默认低电平一定停机。驱动板使用独立功率供电支路，可按电源预算共用电池；非隔离 PWM 需信号共地，电机大电流回流不得经过逻辑接口。

水下线缆：ESP32-P4 UART3（GPIO28/29/30）⇄ 独立 RS485 收发器 ⇄ A/B 线缆 ⇄ 岸端。暂按双线半双工控制与遥测，视频回传链路另定；与 F4 电池、超声波 RS485 分开。缆长、波特率、参考地、终端、隔离保护及穿舱连接器待确认。板内 CAN 连接双 MCU，USB-CAN 用于本地诊断；STM32 独立监测命令超时。

新增外接声纳探鱼模块，由 STM32F4 接收探测结果并按模块协议配置或触发；接口制式、逻辑电平、供电、更新率、数据格式及引脚待定。这里预留的是带信号处理功能的声纳模块接口，不能将裸换能器直接接 MCU。低速深度 / 目标结果可经 CAN → ESP32-P4 → 上位机显示；原始回波或声纳图像需另核算 F4 处理能力和传输带宽，不默认经现有 CAN 转发。

独立温度模块已删除；保留 I²C 深度模块由 STM32F4 读取，候选 I2C2 与 IMU 的 I2C1 分开。电压、地址、上拉、电容与线长按模块核定；必要时缓冲 / 差分延伸或就近采集。深度仍需核对压力类型、量程、耐压、零点、大气压与温度 / 水密度补偿。

LED 照明由 STM32F4 单独预留 LIGHT_CTRL，开关 GPIO 或调光 PWM 按灯型确定，不占原 PWM1–5。灯功率驱动放在板外，可并入独立驱动板：自带驱动灯具按规格开关 / 调光，裸功率 LED 需要恒流驱动。额定电压、电流、功率、散热与防水待定；控制输入硬件默认关闭，复位 / 失联策略需验证。灯电流不经过 MCU 引脚或逻辑电源。

6S 电池通信：智能电池 / BMS 经独立 RS485 收发器连接 STM32 UART，预留 TX/RX 与 DE/RE 方向控制；属于业务接口，不是串口调试口。A/B、参考地、屏蔽、隔离、终端 / 偏置与接插件按电池规格确定；不默认提供接口供电。协议和字段待厂家资料确认，超时标记数据失效。保留电压 ADC 分压 / 滤波 / 保护，用于本地辅助欠压判断。单节满充4.2V时6S满充25.2V，化学体系仍待确认；旧100k/27k分压及旧12V保护 / 降压不能直接沿用。遥测经 CAN → P4 → 上位机；图中跨线无连接点处不表示电气相连。

外部通信模块位于板外：接口1通过 ESP32-P4 UART 接4G / LoRa模块，接口2通过 ESP32-P4 SPI 接2.4GHz模块。图中两块为主板侧接口位置，不表示无线模块集成在主板上；XH2.0为当前连接器候选，针数、供电、信号电平及具体协议按所选模块核对。

布局已调整：双 MCU 居中，UART 激光雷达接口与新增 microSD 卡座位于 P4 侧板边。雷达使用 UART，电平与波特率待型号核对；卡槽候选 SDMMC_HOST_SLOT_0 4bit（GPIO39–44，供电域待核对），slot1候选留给内部C5，6 根信号 + 可选卡检测，不占 2.4GHz SPI。五个超声波采用 RS485：暂按独立地址共总线，经独立收发器连接 USART3（PD8/PD9，PD10 控制方向），与电池 RS485 分开。模块供电和协议待定；轮询仍须避免声学串扰。雷达头是否同板按封装和视场确认。

资源核查：F4使用5/6串口、2/3 I²C、1/2 CAN、五路驱动PWM及独立LED PWM；AIS使用UART5，LED使用PB8/TIM10。P4使用3路HP UART；42个GPIO分配、2个内部共享、5个启动恢复，无空闲通用脚。USB/CSI/DVP三摄接口需I²C控制扩展器，同地址SCCB需隔离/多路复用。SD使用GPIO39–45，水泵EN使用GPIO31。DMA、并行采集、编码及写卡吞吐待实测；F4按处理模块测距结果进行预算，不含原始声纳成像。
